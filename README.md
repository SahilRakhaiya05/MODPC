# MODPC

Advanced moderation workspace for Reddit communities.

MODPC helps moderators manage queues, modmail, Automod, moderator actions, AI-assisted workflows, and anti-spam systems from one unified interface.

Built for real subreddit operations with moderator-first safety and live Reddit integration.

---

## Main Features

- Queue moderation
- Modmail management
- Automod tools
- Moderator logs
- AI moderation assistant
- Anti-bot protection
- Team collaboration
- Risk monitoring
- Native Reddit integrations

---

## AI Features

Sentinel AI helps moderators:

- Draft safe replies
- Review moderation context
- Detect risks
- Speed up moderation workflows

---

## Anti-Spam Protection

CommentCop detects copied and spam-like comments using similarity analysis and moderation triggers.

---

## Safety System

Live moderation actions require:

- Moderator permissions
- Reddit authentication
- Explicit confirmation
- Runtime safety checks

---

## Built With

- Devvit Web
- React 19
- Hono

- Redis
- Gemini/OpenAI/GROQ

## Access

Publicly discoverable on Reddit Developer Platform.

Workspace access is restricted to subreddit moderators.
